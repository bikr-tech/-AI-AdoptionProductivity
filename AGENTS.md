# AGENTS.md — Global AI Adoption and Productivity Analysis

## Project structure

```
backend/                   # FastAPI backend (uv-managed)
  app/
    main.py                # Routes: POST /predict, GET /analytics/summary, GET /health
    schemas.py             # Pydantic request/response models
  models/                  # Model artifacts (gitignored)
    model.pkl              # Trained pipeline: {preprocessor, model}
    split_data.joblib      # Train/test splits (optional)
  pyproject.toml           # uv package config
frontend/                  # Vite + React + Tailwind
  src/
    App.jsx
    components/            # MetricsBanner, PredictorForm, IndustryChart, FeatureImportance
    api/client.js          # fetch wrappers for /predict and /analytics/summary
notebooks/
  kaggle_training.ipynb    # Data generation, preprocessing, training notebook
```

## Data handling

- Raw CSV lives at `data/raw/global_ai_adoption.csv` (gitignored)
- Model artifacts in `backend/models/` (gitignored, generated by notebook)
- Feature importance CSV written to `output/figures/feature_importance.csv`

## Commands

```bash
# Backend (run from backend/ directory)
cd backend
uv sync                          # Install deps from pyproject.toml
uv run uvicorn app.main:app --reload --port 8000

# Or without uv:
uvicorn app.main:app --reload --port 8000

# Frontend
cd frontend
npm install
npm run dev                      # Serves on :5173, proxies /api -> :8000

# Run notebook (generates data + trains model)
jupyter nbconvert --to notebook --execute notebooks/kaggle_training.ipynb
# or open in Jupyter / VS Code and run cells sequentially
```

## API endpoints

| Method | Path                  | Description                              |
|--------|-----------------------|------------------------------------------|
| GET    | `/health`             | Server + model status                    |
| POST   | `/predict`            | Predict productivity gain from user input |
| GET    | `/analytics/summary`  | Precomputed aggregations for dashboard    |

## Gotchas

- Windows cp1252 encoding: avoid Unicode arrows/special chars in print/format strings
- Model must exist at `backend/models/model.pkl` before `/predict` works — run notebook first
- Synthetic data generator injects ~1.5% missing values; preprocessing pipeline handles with imputation
- Feature encoding: `OrdinalEncoder` with `unknown_value=-1` for unseen categories at inference

## Conventions

- `backend/app/main.py` contains all routes (no separate router modules)
- Pydantic models in `backend/app/schemas.py`
- Frontend API client in `frontend/src/api/client.js`
- Keep notebooks cleared of cell outputs before commit
